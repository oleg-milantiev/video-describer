# Video Describer

Полный конвейер анализа и авто монтажа видео через локальный LLM. 

## Что делает пакет

Автоматически разбирает исходные видеоматериалы: извлекает кадры, транскрибирует речь, описывает каждый шот с драматургическим анализом (сцены, месседж, визуальные приёмы), а затем собирает монтажный черновик по текстовому промпту. Результат — готовый `.fcpxml`/`.mp4`, который остаётся в timeline NLE (DaVinci Resolve, Premiere) для финального наложения музыки и цветокора.

**Производительность:**

Для примера моя сборка, включающая:
- Windows с self-hosted LLM-инференсом Qwen3.6-35B-A3B Q4 через Poly Strata
- NVIDIA 3060, 12 ГБ VRAM
- AMD Ryzen 7 3700x, 64 ГБ DDR4.

Даёт такие тайминги в default настройках:
- Анализ видео: 1/3×…5× realtime (зависит от длины, количества кадров и LLM-задержки)
- Монтаж минутного ролика из ~12 фрагментов: 3…5 минут

## Типичный use case

1. Закидываешь видео поездки в Грузию (`*.mp4`) в папку проекта.
2. `voice.py` транскрибирует весь аудио — получает `-voice.json`.
3. `describe-video.py` анализирует каждый кадр + расшифровку — получает `-shots.md` с драматургией, сценами, таймкодами.
4. `director.py ./папка --prompt "Собери короткий динамичный ролик"` — LLM выбирает лучшие шоты, выстраивает хронологию, генерирует `draft.mp4` и `.fcpxml`.
5. Просматриваешь черновик `draft.mp4`, понимаешь то или не то.
6. Открываешь `.fcpxml` в DaVinci Resolve, накладываешь заранее выбранную грузинскую музыку (132 BPM), делаешь цветокор, экспортишь финал.

## Компоненты

| Скрипт | Назначение | Вход | Выход |
|--------|-----------|------|-------|
| `voice.py` | Транскрипция аудио (Whisper) | `*.mp4` | `{basename}-voice.json` |
| `describe-video.py` | Анализ кадров + синхронизация с голосом | `*.mp4`, `*-voice.json` | `{basename}-shots.md` |
| `director.py` | ИИ-монтаж: выбор шотов, сборка ролика | `*-shots.md` + исходники | `draft.mp4`, `.fcpxml` |

## Быстрый старт

### 1. Транскрипция

```bash
python voice.py путь/к/видео.mp4
```

Создаёт `{basename}-voice.json` с сегментами речи и таймкодами.

### 2. Анализ видео

```bash
python describe-video.py путь/к/видео.mp4
```

- Извлекает кадры (JPG, 768px сторона) через ffmpeg
- Загружает `*-voice.json` из той же папки
- Отправляет кадры + расшифровку в визуальный LLM
- Сохраняет структурированный анализ в `{basename}-shots.md`

**Параметры:**
- `--fps N` — частота кадров (по умолч. 1)
- `--size N` — ширина для горизонтальных / высота для вертикальных (по умолч. 768)
- `--base_url URL` — endpoint LLM (по умолч. `http://127.0.0.1:8080/v1`)
- `--api-key KEY` — API-ключ авторизации
- `--model NAME` — имя модели

### 3. Пакетная обработка

```bash
describe-all.cmd
```

Запускает `describe-video.py` для всех `.mp4` в папке.

### 4. Монтаж (director.py)

```bash
python director.py ./папка_с_видео
python director.py ./папка_с_видео --prompt "Динамичная нарезка путешествий"
```

Создаёт `draft.mp4` и `.fcpxml` из имеющихся `-shots.md`.

## Структура выходных данных

### voice.json

```json
{
  "language": "ru",
  "duration": 8.768,
  "segments": [
    {
      "start": 0.0,
      "end": 7.82,
      "text": "...",
      "words": [...]
    }
  ]
}
```

### shots.md

```markdown
## Драматургический анализ

**Месседж/идея:** ...

## Структура и развитие сюжета

- **Начало [ММ:СС]:** завязка...
- **Развитие:** ключевые события...
- **Кульминация/пик:** момент напряжения...
- **Конец [ММ:СС]:** развязка...

## Сцены (если более одной)

### Сцена 1 [ММ:СС — ММ:СС]
- **Визуальное содержание:** ...
- **Аудиосопровождение:** ...
- **Синхронизация:** ...

## Визуальные приёмы и ключевые моменты
```

## Зависимости

- Python 3.12+
- `faster-whisper` — транскрипция аудио
- ffmpeg (portable: `E:\PORTABLE\ffmpeg\bin`)
- Локальный LLM-сервер с OpenAI-compatible API (`/v1/chat/completions`)

  (не обязательно локальный. Можно использовать любой облачный LLM, понимающий картинки)
